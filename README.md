# Rock Paper Scissors Game

An interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript with dynamic gameplay, score tracking, autoplay mode, and responsive UI design.

## Features
- Play against the computer
- Randomized computer moves
- Live score updates
- Autoplay feature
- Interactive button animations and hover effects
- Responsive and visually engaging interface

## Tech Stack
- HTML
- CSS
- JavaScript
